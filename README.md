# Sandy Sports Club | proposed club and shared system

Sandy Sports is a **proposed**, mixed-sport, three-town community club for Minjerribah / North Stradbroke Island. No incorporated club, appointed committee, active memberships, approved events or land tenure is asserted. The vision centres on mixed beach volleyball with flag football, beach cricket, football, beach rugby, AirBadminton, tennis/net sports, ultimate, handball, fitness, wellbeing, inclusive recreation, world-class modular outdoor LED cinema and local cultural programming.

## One full club system

The staged backend is intended to run alongside the public pages under the same Cloudflare Worker domain. It contains:

- Role-based real webmaster, reserved office holder accounts, view-only synthetic webmaster demo, secure sessions and a gated bootstrap. No office-holder invitations are sent or generated by default.
- Shared directory of people and future memberships, with search/sort by joining date, renewal date, voluntary gender, town, class/status, origin and consent; no invented member records.
- Consent-gated expressions of interest for residents and QLD/NSW holidaymakers with Cloudflare Turnstile, currently unavailable until configured.
- Shared committees, minutes and events, grants, assets, proposed facilities, safeguarding, sponsorship, volunteering, newsletters, film and social ideas in a versioned D1 register.
- Social Studio settings, individual post edits and performance-import history with optimistic concurrency and server-stamped actor, office, UTC timestamp and revision snapshots.
- Production briefs and **proposed** Ready SET Co-op handoffs, committee review, formal decision references and published links. Formal approval is disabled until the club has legitimate decision-makers.
- A member self-service portal for **only the signed-in member's linked record**, with approved future events; activation depends on proper formation and policies.

The shared APIs are protected against cross-origin state changes; client-side hidden buttons alone are not treated as authorisation. The first webmaster setup requires Cloudflare-only secrets and must be completed with the actual administrator, never a fabricated account.

**The code is not yet a fully operating club service.** The Cloudflare account owner must provision a **separate Sandy D1 database**, apply `0001_club.sql`, set private authentication secrets and switch to the full Worker configuration. See [backend/README.md](backend/README.md) for the exact sequence. Do **not** reuse the existing PLFC database or its credentials.

## Social Studio and PLFC comparison

The PLFC-inspired Studio uses 32 Sandy topic layers with weekday/Friday/weekend/public-holiday day-type minimums and maximums, individual icon displays, strong Past/Today/Future styling, Brisbane-time scheduling, optional QLD/NSW school-holiday boosts, event signals and follow-up content. It supports YouTube, Facebook, Instagram, TikTok and the proposed Straddie Noticeboard Network, with versioned media specifications and paid creative *planning*, not purchases.

The exact parity boundary is documented in [studio/PLFC-PARITY.md](studio/PLFC-PARITY.md). PLFC's live membership and signed approval records are not imported into Sandy; Sandy's independent backend is staged to supply equivalent authenticated mechanisms once activated. All older browser-only ideas and Studio plans are preserved for deliberately reviewed migration.

## Hosting and source

- Public pages and assets use the original standalone HTML, `site.js`, `styles.css`, `pages.css` and `build_pages.py`; the seven-item top menu stays compact while the footer has the full page directory. Do not use `build_pages.py` to overwrite manually maintained Studio pages.
- `.assetsignore` must exclude Worker source, server tests, database schema, credentials and deployment configuration from static assets.
- A **separate** full Worker config is staged as `wrangler.full.example.jsonc`. Its D1 database UUID is intentionally a placeholder. Do not publish or deploy that placeholder as though it were real.
- The existing `.github/workflows/validate.yml` checks JavaScript syntax, a clean SQLite migration and tests. No successful CI run proves Cloudflare D1 is provisioned, data has been migrated or the site is authenticated.
- The site is currently stewarded by its proponent, Luke Nathan Hayes / Strange But True, under the [interim public source licence](LICENCE.md). See [third-party and asset notes](LICENSE.md).
