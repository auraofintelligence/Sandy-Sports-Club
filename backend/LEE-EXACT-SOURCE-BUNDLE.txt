# Sandy Sports Club: activating shared Cloudflare records

**Status:** the Worker API, D1 migration, sign-in, member/committee screens and Social Studio client have been prepared in this repository. **They are not live merely because GitHub has these files.** The currently deployed \`wrangler.jsonc\` remains assets-only until the required Sandy database and secrets are provisioned.

Sandy Sports is still a proposal. Do not insert real members, appoint unapproved office holders, send invitations, accept payments, commission Ready SET Co-op or enable formal publication decisions.

## Cloudflare setup required

Use a **new, independent D1 database** for Sandy. Do not reuse PLFC's database, account keys or roles.

1. Create the database in the same Cloudflare account as the Sandy Worker. Example: \`npx wrangler d1 create sandy-sports-club\`. Copy its D1 **database UUID** (not a password).
2. Copy \`wrangler.full.example.jsonc\` to a temporary \`wrangler.full.jsonc\`, replacing \`REPLACE_WITH_NEW_SANDY_D1_UUID\`. Its Worker name is \`sandy-sports-club\`, with \`DB\` bound only to this new database.
3. Apply \`backend/migrations/0001_club.sql\` using Wrangler D1 migrations against the **remote Sandy DB**: \`npx wrangler d1 migrations apply DB --remote --config wrangler.full.jsonc\`. Review the target name and backup before applying.
4. Set two independently generated high-entropy secrets on the *Sandy* Worker, via Cloudflare's dashboard or \`npx wrangler secret put SANDY_AUTH_PEPPER\` and \`npx wrangler secret put SANDY_BOOTSTRAP_KEY\`. Each must be at least 32 characters. **Never put these values in GitHub, chats or exported reports.**
5. Keep \`SANDY_CLUB_APPROVALS="disabled"\` and \`SANDY_INVITES_ENABLED="disabled"\`. Do not enable them as an installation step.
6. Replace the live repository's \`wrangler.jsonc\` with the reviewed full configuration **only after** steps 1 to 5 have succeeded and the tests pass. The existing public files remain in their current root and \`.assetsignore\` excludes Worker source, database schema, tests and secrets from static delivery.
7. Verify \`/api/health\` reports \`storageConfigured:true\` and \`authConfigured:true\`. Confirm \`/api/session\` does not report any identity when signed out.
8. Visit \`/club-login.html\`, open "First webmaster setup", and use the private bootstrap key to create the actual webmaster username/password. This is permitted **once only** while the accounts table is empty. Remove \`SANDY_BOOTSTRAP_KEY\` from Cloudflare secrets immediately afterward.
9. Log in at \`/club-login.html\` and visit \`/club-admin.html\`. Reserve desired office-holder accounts without issuing invitations. Create a \`webmaster_demo\` reserved account only when needed; the server exposes synthetic, view-only demo information to that role.
10. Visit \`/social-studio.html\` while signed in. The Studio uses authenticated D1 settings, revisions, per-post edits and imported performance metrics. Older browser-local drafts may be explicitly imported by the webmaster, **never automatically**. Review their contents before bringing them into the shared record.

Official configuration reference: https://developers.cloudflare.com/workers/static-assets/binding/ and https://developers.cloudflare.com/d1/reference/migrations/

## Optional visitor interest collection

The public \`/interest.html\` form remains disabled until both Cloudflare Turnstile credentials are configured:

- Add a Turnstile widget for the Sandy Worker origin, set the public site key as \`SANDY_TURNSTILE_SITE_KEY\` in the Worker variables.
- Add \`SANDY_TURNSTILE_SECRET\` as a private Worker secret.
- Confirm that \`/api/public-config\` reports \`publicInterestReady:true\` before sharing the QR/landing page.

The form requests explicit contact consent and stores **expressions of interest**, not memberships. No automatic emails, invites, advertising or fundraising are initiated.

## Roles and permissions

| Role | Access |
|---|---|
| Real webmaster | Full authenticated administration; can reserve accounts; cannot claim legal club approval while approvals disabled |
| President / secretary | Committee records; sensitive directory (where permitted); decision authority only after governing activation |
| Vice-president / assistant secretary / treasurer | Committee records; selected directory access per the API |
| Committee | Shared proposals, events and Social Studio; not private membership directory by default |
| Member | No committee authority; member portal activation requires final policies and account linking |
| Webmaster demo | Synthetic view-only preview; never has access to real member or committee data |

Accounts are **reserved**, not invited, by default. The standalone webmaster may preview different interface layouts but cannot forge the logged-in identity of another officer. Every real write records the authenticated actor ID, office, role, UTC timestamp and version. Sensitive read permissions are enforced by the API, not only by hidden buttons.

## Data and approval rules

- The club-formation system has **no seeded member records, payments, assumed office appointments, approved events or invitations**.
- Shared membership records track names, classes, joining/renewal dates, voluntary gender, town, origin and consent. Only designated staff can read them.
- Committee proposals cover events, meetings, tasks, annual calendar, grants, equipment, assets, sponsorship, volunteering, newsletters, governance and media.
- Each record has an optimistic version to prevent silent overwrites and an append-only server revision.
- Social Studio Day/Week/Month settings, individual post edits and performance CSV import results have separate server version history.
- A proposed Ready SET Co-op production brief is not a contract. Authorised commissioning, committee decisions and publishing links require a separate role-gated workflow.
- Formal approvals are disabled until the club is properly established and its actual delegation arrangements are adopted. They cannot be enabled by a browser toggle.
- No SMS, automated social publishing, payment processing or advertising expenditure is connected.
- Put backup, retention, privacy, consent, safeguarding, Cloudflare Access/MFA and operator account recovery policies in place before admitting real sensitive member data. Password sign-in alone is not a substitute for those organisational controls.

## Validation before activation

The repository includes:
- \`tests/schema-check.py\` for applying the D1 SQL migration to a clean SQLite database and confirming that it seeds no fake club records.
- \`tests/shared-club-backend.test.mjs\` for access and deployment safety checks.
- Existing Sandy calendar, media layout and time-of-day regression tests.
- GitHub workflow \`.github/workflows/validate.yml\` that checks server JavaScript syntax, database migration and unit tests.

Do not enable the Worker API if any validation fails. If any shared endpoint returns an error, do not treat a browser-local backup as a successful database save.

## Deployment boundary

The actual Cloudflare account administrator must create the database, set the secrets, apply the migration and switch the deployment configuration. A GitHub commit cannot invent those Cloudflare resources or create a functioning authenticated service. Until then the existing live static site remains the safe public version and the full shared club system is **staged, not deployed**.

// secrets have been provisioned; this is separate from PLFC's live database.

import {identityFor,authEndpoint} from './auth.mjs';
import {peopleEndpoint,interestEndpoint} from './people.mjs';
import {recordsEndpoint} from './records.mjs';

const defaults={
 'Cache-Control':'no-store, private',
 'X-Content-Type-Options':'nosniff',
 'Referrer-Policy':'no-referrer',
 'Cross-Origin-Resource-Policy':'same-origin',
 'X-Frame-Options':'DENY'
};
const respond=(data,status=200)=>new Response(JSON.stringify(data),{
 status,headers:{...defaults,'Content-Type':'application/json; charset=utf-8'}
});
function safePath(req){
 const url=new URL(req.url);
 if(url.pathname.length>300)throw new ApiError(414,'This endpoint path is too long.','invalid_path');
 return url.pathname;
}
async function handle(req,env){
 const path=safePath(req);
 if(!path.startsWith('/api/'))return env.ASSETS?.fetch(req)||new Response('Static assets not configured.',{status:503});
 if(!['GET','POST','PATCH','HEAD'].includes(req.method))throw new ApiError(405,'That method is not supported.','method_not_allowed');
 if(!['GET','HEAD'].includes(req.method))verifySameOrigin(req);
 if(path==='/api/public-config'&&req.method==='GET')
  return respond({clubEstablished:env.SANDY_CLUB_APPROVALS==='enabled',
   publicInterestReady:Boolean(env.DB?.prepare&&env.SANDY_TURNSTILE_SECRET&&env.SANDY_TURNSTILE_SITE_KEY),
   turnstileSiteKey:env.SANDY_TURNSTILE_SITE_KEY||null,invitationSendingEnabled:false});
 if(path==='/api/health'&&req.method==='GET')
  return respond({service:'sandy-club',storageConfigured:Boolean(env.DB?.prepare),
   authConfigured:Boolean(env.SANDY_AUTH_PEPPER?.length>=32),operationalApprovals:env.SANDY_CLUB_APPROVALS==='enabled',
   livePublishing:false,smsEnabled:false,paymentsEnabled:false});
 const identity=await identityFor(req,env);
 if(path==='/api/session'||path.startsWith('/api/auth/')||path==='/api/accounts'||
  path.startsWith('/api/accounts/')||path==='/api/demo')
  return authEndpoint(req,env,path,identity);
 if(path==='/api/member/me'||path==='/api/member/events')
  return memberEndpoint(req,env,path,identity);
 if(path==='/api/interest'||path.startsWith('/api/interest/'))
  return interestEndpoint(req,env,path,identity);
 if(path==='/api/people'||path.startsWith('/api/people/'))
  return peopleEndpoint(req,env,path,identity);
 if(path==='/api/records'||path.startsWith('/api/records/')||path==='/api/committee/events'||path==='/api/meetings')
  return recordsEndpoint(req,env,path,identity);
 if(path==='/api/committee/social-campaign-settings'||path==='/api/committee/social-post-edits'||path==='/api/committee/social-metrics')
  return socialEndpoint(req,env,path,identity);
 if(path==='/api/studio/briefs'||path.startsWith('/api/studio/briefs/'))
  return briefsEndpoint(req,env,path,identity);
 if(path==='/api/audit')return auditEndpoint(req,env,identity);
 throw new ApiError(404,'No club service exists at this address.','not_found');
}
export default {
 async fetch(req,env,ctx){
  try{
   const response=await handle(req,env);
   if(!new URL(req.url).pathname.startsWith('/api/'))return response;
   const headers=new Headers(response.headers);
   for(const [name,value] of Object.entries(defaults))headers.set(name,value);
   return new Response(response.body,{status:response.status,headers});
  }catch(error){
   if(!(error instanceof ApiError))console.error('Sandy API failure:',String(error?.message||error).slice(0,240));
   const status=error instanceof ApiError?error.status:500;
   return respond({error:error instanceof ApiError?error.message:'The shared club service could not complete this request.',
    code:error instanceof ApiError?error.code:'server_error'},status);
  }
 }
};

export const STAFF=['webmaster','president','vice_president','secretary','assistant_secretary','treasurer','committee'];

const headers={'Content-Type':'application/json; charset=utf-8','Cache-Control':'no-store, private','X-Content-Type-Options':'nosniff','Referrer-Policy':'no-referrer'};
export class ApiError extends Error{
 constructor(status,message,code='request_failed'){super(message);this.status=status;this.code=code}
}
export const fail=(status,message,code)=>{throw new ApiError(status,message,code)};
export const json=(data,status=200,extra={})=>new Response(JSON.stringify(data),{status,headers:{...headers,...extra}});
export const now=()=>new Date().toISOString();
export const epoch=()=>Math.floor(Date.now()/1000);
export const id=()=>crypto.randomUUID();
export const dbFor=env=>{
 if(!env.DB?.prepare)fail(503,'Shared Sandy database is not configured. No committee data was saved.','database_unavailable');
 return env.DB.withSession?env.DB.withSession('first-primary'):env.DB;
};
export const staff=identity=>Boolean(identity&&STAFF.includes(identity.role));
export function requireRole(identity,roles=STAFF){
 if(!identity)fail(401,'Sign in to access shared club records.','login_required');
 if(identity.role==='webmaster'&&roles.includes('webmaster'))return identity;
 if(!roles.includes(identity.role))fail(403,'Your account cannot access this record.','forbidden');
 return identity;
}
export function ensureMemberData(identity){
 requireRole(identity,['webmaster','president','secretary','assistant_secretary','treasurer']);
}
export function ensureWriter(identity){
 requireRole(identity,STAFF);
}
export function ensureApprover(identity,env){
 requireRole(identity,APPROVERS);
 if(env.SANDY_CLUB_APPROVALS!=='enabled')fail(409,'Formal club approval is disabled until the club has lawful governing authority. Record a proposal instead.','club_not_established');
}
export async function payload(req,max=65536){
 const size=Number(req.headers.get('content-length')||0);
 if(size>max)fail(413,'The submission is too large.','too_large');
 const type=req.headers.get('content-type')||'';
 if(!type.toLowerCase().includes('application/json'))fail(415,'Send a JSON request.','invalid_content_type');
 const raw=await req.text();
 if(raw.length>max)fail(413,'The submission is too large.','too_large');
 try{
  const obj=JSON.parse(raw);
  if(obj===null||typeof obj!=='object'||Array.isArray(obj))throw Error('invalid JSON');
  return obj;
 }catch{fail(400,'The request body must be a JSON object.','invalid_json')}
}
export const field=(value,max=200)=>typeof value==='string'?value.trim().slice(0,max):'';
export function dateField(value,nullable=true){

 brief:row.brief,producer:row.producer,reviewer:row.reviewer,status:row.status,due:row.due,
 author:row.author_note,decisionBy:row.decision_by_note,evidence:row.evidence,publishedUrl:row.published_url,
 notes:row.notes,createdBy:row.created_by,updatedBy:row.updated_by,createdAt:row.created_utc,updatedAt:row.updated_utc
});
function clean(b){
 const state=field(b.status,30)||'draft',title=field(b.title,180);
 if(!title||!mutable.includes(state))fail(400,'Enter a title and a valid draft, review or withdrawn state. Formal approvals require a separate decision.','invalid_brief');
 return {title,date:dateField(b.date),sourcePostId:field(b.sourcePostId||b.reference,180),sourceUrl:https(b.sourceUrl),
  brief:field(b.brief,6000),producer:field(b.producer,100)||'in-house',reviewer:field(b.reviewer,100)||'founding',
  status:state,due:dateField(b.due),author:field(b.author,100),decisionBy:field(b.decisionBy,100),
  evidence:https(b.evidence),publishedUrl:https(b.publishedUrl),notes:field(b.notes,6000)};
}
const saveFields='title,date,source_post_id,source_url,brief,producer,reviewer,status,due,author_note,decision_by_note,evidence,published_url,notes';
const values=b=>[b.title,b.date,b.sourcePostId,b.sourceUrl,b.brief,b.producer,b.reviewer,b.status,b.due,b.author,b.decisionBy,b.evidence,b.publishedUrl,b.notes];
async function briefs(db){
 const r=await db.prepare('SELECT * FROM studio_briefs ORDER BY updated_utc DESC LIMIT 300').all();
 return (r.results||[]).map(toView);
}
export async function briefsEndpoint(req,env,path,identity){
 requireRole(identity,STAFF);const db=dbFor(env),at=now();
 if(path==='/api/studio/briefs'&&req.method==='GET')return json({briefs:await briefs(db)});
 if(path==='/api/studio/briefs'&&req.method==='POST'){
  const b=clean(await payload(req,20000)),briefId=id();
  await db.batch([
   db.prepare('INSERT INTO studio_briefs(id,'+saveFields+',version,created_by,updated_by,created_utc,updated_utc) VALUES(?,?,?,?,?,?,?,?,?,?,?,?,?,?,?,1,?,?,?,?)')
    .bind(briefId,...values(b),identity.id,identity.id,at,at),
   revision(db,{kind:'studio-brief',resourceId:briefId,resourceVersion:1,action:'created',actor:identity,at,snapshot:b}),
   audit(db,identity,'production_brief_created','studio-brief',briefId,at)
  ]);
  return json({ok:true,id:briefId,version:1},201);
 }
 const match=path.match(/^\/api\/studio\/briefs\/([a-f0-9-]{36})(?:\/(revisions|decision|handoff|publish-link))?$/);
 if(!match)fail(404,'Unknown production brief operation.','not_found');
 const briefId=match[1],row=await db.prepare('SELECT * FROM studio_briefs WHERE id=?').bind(briefId).first();
 if(!row)fail(404,'The production brief does not exist.','brief_not_found');
 if(req.method==='GET'){
  if(match[2]==='revisions'){
   const q=await db.prepare("SELECT resource_version AS version,at_utc AS at,actor_role AS role,actor_office AS office,changes_json AS changes FROM club_revisions WHERE resource_kind='studio-brief' AND resource_id=? ORDER BY resource_version DESC LIMIT 80").bind(briefId).all();
   return json({revisions:(q.results||[]).map(r=>({...r,changes:JSON.parse(r.changes)}))});
  }
  if(!match[2])return json({brief:toView(row)});
 }
 if(!match[2]&&req.method==='PATCH'){
  const b=await payload(req,20000),expected=version(b.version);
  if(row.version!==expected)fail(409,'Another officer updated this production brief. Reload it.','conflict');
  if(!mutable.includes(row.status))fail(409,'Authorised production records cannot be silently edited. Open a new revision for review.','approved_locked');
  const data=clean({...toView(row),...b});
  const [result]=await db.batch([
   db.prepare('UPDATE studio_briefs SET '+saveFields.split(',').map(f=>f+'=?').join(',')+',version=version+1,updated_by=?,updated_utc=? WHERE id=? AND version=?')
    .bind(...values(data),identity.id,at,briefId,expected),
   revision(db,{kind:'studio-brief',resourceId:briefId,resourceVersion:expected+1,action:'updated',actor:identity,at,
    snapshot:data,changes:{changed:Object.keys(b).filter(x=>x!=='version')},guarded:true}),
   audit(db,identity,'production_brief_updated','studio-brief',briefId,at,true)
  ]);
  if(!result.meta.changes)fail(409,'This brief changed before the update completed.','conflict');
  return json({ok:true,id:briefId,version:expected+1});
 }
 if(match[2]==='decision'&&req.method==='POST'){
  ensureApprover(identity,env);
  const b=await payload(req,8192),expected=version(b.version),decision=field(b.decision,32),evidence=https(b.evidence);
  if(row.version!==expected)fail(409,'Review the latest brief revision first.','conflict');
  if(!evidence||!['approved','rejected','returned','publish_authorised'].includes(decision))
   fail(400,'Select a valid decision and add a supporting HTTPS reference.','invalid_decision');
  if(decision==='publish_authorised'&&row.status!=='approved')fail(409,'The brief must be approved before publication may be authorised.','not_approved');
  const newStatus=decision==='returned'?'revision':decision==='publish_authorised'?'approved':decision,newVersion=row.version+1;
  const decisionId=id();
  const [result]=await db.batch([
   db.prepare('UPDATE studio_briefs SET status=?,version=version+1,updated_by=?,updated_utc=? WHERE id=? AND version=?')

    .bind(decisionId,briefId,newVersion,decision,JSON.stringify({title:row.title,producer:row.producer}),evidence,identity.id,identity.office_label,at),
   revision(db,{kind:'studio-brief',resourceId:briefId,resourceVersion:newVersion,action:'decision_'+decision,actor:identity,at,
    snapshot:{...toView(row),status:newStatus,version:newVersion},changes:{decision,evidence},guarded:true}),
   audit(db,identity,'studio_decision_'+decision,'studio-brief',briefId,at,true)
  ]);
  if(!result.meta.changes)fail(409,'This brief changed while recording the decision.','conflict');
  return json({ok:true,decisionId,version:newVersion});
 }
 if(match[2]==='handoff'&&req.method==='POST'){
  const b=await payload(req,8192),producer=field(b.producer,100),due=dateField(b.due);
  if(!producer)fail(400,'Choose a prospective production provider.','invalid_producer');
  const authorised=env.SANDY_CLUB_APPROVALS==='enabled'&&b.authorised===true;

   db.prepare('INSERT INTO studio_handoffs(id,brief_id,decision_id,producer,status,requested_delivery_on,updated_utc,issued_by,issued_utc) VALUES(?,?,?,?,?,?,?,?,?)')
    .bind(handoffId,briefId,decision?.id||null,producer,authorised?'authorised':'proposed',due,at,authorised?identity.id:null,authorised?at:null),
   audit(db,identity,authorised?'handoff_authorised':'handoff_proposed','studio-brief',briefId,at)
  ]);
  return json({ok:true,handoffId,state:authorised?'authorised':'proposed',sent:false},201);
 }
 if(match[2]==='publish-link'&&req.method==='POST'){
  const b=await payload(req,8192),url=https(b.url),platform=field(b.platform,30);
  if(!url||!['youtube','facebook','instagram','tiktok','noticeboard'].includes(platform))fail(400,'Provide a verified platform and HTTPS post link.','invalid_publication_link');
  const decision=await db.prepare("SELECT id FROM studio_decisions WHERE entity_type='studio_brief' AND entity_id=? AND decision='publish_authorised' ORDER BY decided_utc DESC LIMIT 1").bind(briefId).first();
  if(!decision)fail(409,'Publishing has not been authorised. The link cannot be recorded as approved.','publication_not_authorised');
  const linkId=id();
  await db.batch([
   db.prepare('INSERT INTO studio_post_links(id,brief_id,decision_id,platform,published_url,published_utc,recorded_by,recorded_utc) VALUES(?,?,?,?,?,?,?,?)')
    .bind(linkId,briefId,decision.id,platform,url,dateField(b.publishedOn)?dateField(b.publishedOn)+'T00:00:00+10:00':null,identity.id,at),
   audit(db,identity,'published_link_recorded','studio-brief',briefId,at)
  ]);
  return json({ok:true,linkId},201);
 }
 fail(404,'Unsupported production brief operation.','not_found');
}

export function normaliseDailyLimits(existing={}){
  const output={...DEFAULT_DAILY_LIMITS};
  const legacy=Object.keys(existing).sort().join(',')==='friday,holiday,weekday,weekend';
  for(const {id} of POSTING_DAY_TYPES){
    const max=existing[id],min=existing[id+'Min'];
    if(Number.isInteger(max))output[id]=Math.max(1,Math.min(20,id==='weekday'&&legacy&&max===2?4:max));
    if(Number.isInteger(min))output[id+'Min']=Math.max(1,Math.min(20,min));
    output[id]=Math.max(output[id],output[id+'Min']);
  }
  return output;
}

function assignWeek(days,settings,postsByDay){
  // Preserve the normal week's pattern for every unaffected day. Individual day,
  // Monday-start week and month overrides only replace their selected dates.
  const baseline=new Map(days.map(day=>[day,[]]));
  assignSegment(days,settings,baseline);
  const groups=new Map();
  for(const day of days){
    const selected=settingsForDate(settings,day);
    if(selected===settings){postsByDay.get(day).push(...baseline.get(day));continue;}
    if(!groups.has(selected))groups.set(selected,[]);
    groups.get(selected).push(day);
  }
  for(const [config,scopedDays] of groups){
    const scoped=new Map(scopedDays.map(day=>[day,[]]));
    assignSegment(scopedDays,config,scoped);
    for(const day of scopedDays)postsByDay.get(day).push(...scoped.get(day));
  }
}
function assignSegment(days,settings,postsByDay){
  const key=days[0].slice(0,7)+'-'+days[0];
  for(const layer of CAMPAIGN_LAYERS){
    const preference=settings.layers[layer.id];
    if(!preference?.enabled || !preference.weekly) continue;
    let eligible=days.filter(day=>!layer.holidayOnly||(layer.id==='nswHolidays'?inNSWHoliday(day):inHoliday(day)));
    if(layer.id==='weather')eligible=eligible.filter(day=>[4,5,6].includes(weekday(day)));
    const isQLDWeek=days.some(inHoliday),isNSWWeek=days.some(inNSWHoliday);
    const boost=isQLDWeek && ['volleyball','other','safety','visitors','voice','health'].includes(layer.id)?1:
      !isQLDWeek && isNSWWeek && layer.id==='visitors'?1:0;
    const westernOnly=layer.id==='nswHolidays' && eligible.every(day=>!inNSWEasternHoliday(day));
    const weekly=days.length>=7?preference.weekly:Math.ceil(preference.weekly*days.length/7);
    const frequency=Math.min(eligible.length,westernOnly?Math.min(weekly,1):weekly+boost);
    eligible.sort((a,b)=>{
      const weight=day=>(layer.id==='nswHolidays' && inNSWHoliday(day) && !inHoliday(day)?70:0)+
        (inHoliday(day)?45:0)+([5,6,0].includes(weekday(day))?20:0)+(weekday(day)===5?10:0);
      return weight(b)-weight(a) || numberHash(layer.id+key+a)%100-numberHash(layer.id+key+b)%100;
    });
    const chosen=layer.id==='weather' ? eligible.sort((a,b)=>weekday(a)-weekday(b)).slice(0,frequency) : eligible.slice(0,frequency);
    for(const day of chosen){const post=basePost(layer,day,key,chosen.indexOf(day));post.audience=preference.audience;postsByDay.get(day).push(post);}
  }
}

  for(const event of events){
    const rule=rules[event.kind];
    if(!rule?.enabled)continue;
    const imported=String(event.id||'').startsWith('m-import-');
    const tentative=imported&&!event.confirmed;
    const layer=event.kind==='holidays'?'holidays':event.kind==='nswHolidays'?'nswHolidays':
      event.kind==='meeting'?'events':event.kind.startsWith('programme_')?'events':'events';
    if(tentative){
      // A working committee calendar should inform private content preparation,
      // but a tentative date must never become a public invitation by default.
      const chosen=rule.leadDays.filter(n=>n>=7).sort((a,b)=>a-b)[0]||7;
      const draftDate=iso(dayMs(event.date)-chosen*MS);
      const config=settingsForDate(settings,draftDate);
      if(postsByDay.has(draftDate)&&config.layers[layer]?.enabled){
        postsByDay.get(draftDate).push({
          id:'anchor-planning-'+event.id+'-'+event.date,
          date:draftDate,layerIds:[layer],
          title:'Tentative event planning: '+event.title,
          brief:'Internal draft only. Ask the committee to confirm the event date, permissions and promotional wording before publishing any announcement. Keep room for unexpected opportunities.',
          cta:'Confirm the committee event calendar',audience:config.layers[layer].audience,
          priority:11,sections:['Provisional planning only'],composite:false,status:'suggestion',
          timingSignal:{kind:event.kind,title:event.title,targetDate:event.date,leadDays:chosen,
            tentative:true,phase:'planning',importedCalendar:true,sourceUrl:''}
        });
      }
      continue;
    }
    for(const leadDays of rule.leadDays){
      const date=iso(dayMs(event.date)-leadDays*MS);
      if(!postsByDay.has(date))continue;
      const selected=settingsForDate(settings,date);
      if(!selected.layers[layer]?.enabled)continue;
      const topic=event.title||signalTitles[event.kind]||'Confirmed milestone';
      const label=leadDays>=7?Math.round(leadDays/7)+' weeks':leadDays+' days';
      const title=event.kind==='holidays'||event.kind==='nswHolidays'?
        'Holiday inspiration: '+label+' before '+topic:
        label+' until '+topic+': prepare an informative club update';
      const brief=event.kind==='holidays'||event.kind==='nswHolidays'?
        'Early visitor inspiration and trip-planning ideas. Verify travel, bookings and local conditions; do not imply confirmed club events.':
        'A lead-in idea linked to a user-confirmed milestone. Verify dates, permissions, rules and the source again before posting.';
      postsByDay.get(date).push({
        id:'signal-'+event.kind+'-'+event.date+'-'+leadDays+'-'+(event.id||'standard'),
        date,layerIds:[layer],title,brief,
        cta:event.kind==='holidays'||event.kind==='nswHolidays'?'Explore Sandy Sports visitor ideas':'Check verified Sandy Sports progress',
        audience:selected.layers[layer].audience,priority:leadDays<=7?10:6,sections:[title],
        composite:false,status:'suggestion',
        timingSignal:{kind:event.kind,title:topic,targetDate:event.date,leadDays,
          phase:'lead',importedCalendar:imported,tentative:false,sourceUrl:event.sourceUrl||''}
      });
    }
    if(imported&&['event','meeting'].includes(event.kind)){
      for(const [offset,phase] of [[0,'day'],[1,'follow']]){
        const postingDate=iso(dayMs(event.date)+offset*MS),config=settingsForDate(settings,postingDate);
        if(!postsByDay.has(postingDate)||!config.layers[layer]?.enabled)continue;
        const title=phase==='day'?'Event day: '+event.title:'After '+event.title+': prepare a careful recap';
        const brief=phase==='day'?
          'Prepare a day-of post using only the confirmed time, access, event details and permission from the club. Re-check immediately before posting.':
          'Prepare a thank-you or recap only after verifying what actually happened, results, photographs and participant permission. Do not invent attendance, winners or outcomes.';
        postsByDay.get(postingDate).push({
          id:'anchor-'+phase+'-'+event.id+'-'+event.date,
          date:postingDate,layerIds:[layer],title,brief,cta:'Check confirmed club event information',
          audience:config.layers[layer].audience,priority:phase==='day'?13:7,
          sections:[title],composite:false,status:'suggestion',
          timingSignal:{kind:event.kind,title:event.title,targetDate:event.date,
            phase,importedCalendar:true,tentative:false,leadDays:0,sourceUrl:event.sourceUrl||''}
        });
      }
    }
  }
}

function combine(candidates,cap){
  if(!cap)return {posts:[],omitted:candidates.length};
  const selected=candidates.slice(0,cap);
  const overflow=candidates.slice(cap);
  // A short roundup can carry two additional subjects, reducing posting pressure.
  if(overflow.length && selected.length){
    // Never put tentative calendar dates into a public-facing multi-topic roundup.
    const target=selected.find(p=>!p.timingSignal&&p.layerIds[0]!=='safety')||
      selected.find(p=>!p.timingSignal);
    // Do not silently mix targeted member, gender or visitor groups in one post.
    const additions=[];
    for(let i=0;i<overflow.length && additions.length<2;){
      if(target&&!overflow[i].timingSignal&&JSON.stringify(overflow[i].audience)===JSON.stringify(target.audience))
        additions.push(...overflow.splice(i,1));
      else i++;
    }
    if(target){
      target.layerIds.push(...additions.flatMap(p=>p.layerIds));
      target.sections.push(...additions.map(p=>p.title));
    }
    if(target&&additions.length){
      target.composite=true;
      target.title='30-second Sandy Sports sports-and-community roundup: '+target.sections[0];
      target.brief+=' Include concise segments from the other sources; verify every claim.';
    }
  }
  return {posts:selected,omitted:overflow.length};
}
export function generateCampaignYear(startMonth,settings=defaultCampaignSettings()){
  if(!/^20\d\d-(0[1-9]|1[0-2])$/.test(startMonth))throw new Error('Use a YYYY-MM start month.');
  const first=dayMs(startMonth+'-01');
  if(!Number.isFinite(first))throw new Error('Invalid start month.');
  const endDate=new Date(Date.UTC(Number(startMonth.slice(0,4)),Number(startMonth.slice(5))-1+12,1)).getTime();
  const days=[];for(let ms=first;ms<endDate;ms+=MS)days.push(iso(ms));
  const postsByDay=new Map(days.map(day=>[day,[]]));
  let week=[];
  for(const day of days){if(week.length && weekday(day)===1){assignWeek(week,settings,postsByDay);week=[];}week.push(day);}
  if(week.length)assignWeek(week,settings,postsByDay);
  for(const day of days.filter(dayBeforeHoliday)){
    const monthSettings=settingsForDate(settings,day);
    if(!monthSettings.layers.holidays?.enabled)continue;
    postsByDay.get(day).push({id:'holiday-eve-'+day,date:day,layerIds:['holidays'],title:'Queensland school holidays start tomorrow: invite feedback on the proposal',
      brief:'Confirm Queensland state school holiday dates and local conditions before publishing.',cta:'Explore the Sandy Sports proposal',
      audience:monthSettings.layers.holidays.audience,priority:11,sections:['Holiday countdown'],composite:false,status:'suggestion'});
  }
  for(const day of days.filter(dayBeforeNSW)){
    const monthSettings=settingsForDate(settings,day);
    if(!monthSettings.layers.nswHolidays?.enabled)continue;
    postsByDay.get(day).push({id:'nsw-holiday-eve-'+day,date:day,layerIds:['nswHolidays'],title:'NSW school holidays start tomorrow: ask visitors what they would play',
      brief:'Verify NSW term dates and current ferry, weather and outdoor recreation information before publishing.',cta:'Explore the Sandy Sports visitor ideas',
      audience:monthSettings.layers.nswHolidays.audience,priority:9,sections:['NSW holiday lead-in'],composite:false,status:'suggestion'});
  }
  insertTimingSignals(settings,postsByDay);
  const anchorsByDay=new Map();
  for(const milestone of settings.milestones||[]){
    if(!milestone.confirmed&&!String(milestone.id||'').startsWith('m-import-'))continue;
    if(!anchorsByDay.has(milestone.date))anchorsByDay.set(milestone.date,[]);
    anchorsByDay.get(milestone.date).push({
      id:milestone.id,title:milestone.title,kind:milestone.kind,confirmed:milestone.confirmed
    });
  }
  const dayCards=[],posts=[];
  for(const [day,candidates] of postsByDay){
    const effective=settingsForDate(settings,day);
    const bounds=dayPostingBounds(day,effective.limits);
    const eligible=CAMPAIGN_LAYERS.filter(layer=>effective.layers[layer.id]?.enabled&&
      effective.layers[layer.id]?.weekly>0&&
      (!layer.holidayOnly||(layer.id==='nswHolidays'?inNSWHoliday(day):inHoliday(day)))&&
      (layer.id!=='weather'||[4,5,6].includes(weekday(day))));
    // Every day must reach its configured minimum. Use different enabled topics
    // before repeating a layer, and never fabricate official conditions or club events.
    for(let i=candidates.length;eligible.length&&i<bounds.min;i++){
      const present=new Set(candidates.flatMap(post=>post.layerIds));
      const pool=eligible.filter(layer=>!present.has(layer.id));
      const options=pool.length?pool:eligible;
      const picked=options.sort((a,b)=>numberHash(day+'-'+i+'-'+a.id)-numberHash(day+'-'+i+'-'+b.id))[0];
      if(picked){
        const post=basePost(picked,day,'minimum-'+day,i);
        post.id='minimum-'+picked.id+'-'+day+'-'+i;
        post.priority=1;post.audience=effective.layers[picked.id].audience;
        candidates.push(post);
      }else{
        candidates.push({id:'daily-'+day+'-'+i,date:day,layerIds:['daily'],
          title:'Choose Sandy Sports topic '+(i+1)+' for today',
          brief:'Write a genuine sport, wellbeing or community idea using confirmed information. This is an editable planning placeholder.',
          cta:'Visit the club website',audience:{membership:['all'],gender:['all'],place:['all']},
          priority:0,composite:false,sections:['One relevant daily club update'],status:'suggestion'});
      }
    }
    candidates.sort((a,b)=>b.priority-a.priority||numberHash(a.id)-numberHash(b.id));
    // Keep an editorial slot for regular/whimsical content when several annual
    // event reminders coincide. A curated day can intentionally override this.
    if(bounds.max>1){
      const anchors=candidates.filter(p=>p.timingSignal?.importedCalendar);
      const other=candidates.filter(p=>!p.timingSignal?.importedCalendar);
      if(anchors.length>=bounds.max&&other.length){
        candidates.splice(0,candidates.length,...anchors.slice(0,bounds.max-1),
          other[0],...anchors.slice(bounds.max-1),...other.slice(1));
      }
    }
    const dayPlan=settings.dayPlans?.[day];
    // A curated day replaces generated suggestions, not the other way around.
    // The club retains full control even when a monthly pattern is later changed.
    const manual=Array.isArray(dayPlan?.items)&&dayPlan.items.length>0;
    const result=manual?{omitted:0,posts:dayPlan.items.map((slot,index)=>{
      const layer=CAMPAIGN_LAYERS.find(item=>item.id===slot.layerId)||CAMPAIGN_LAYERS.find(item=>item.id==='community');
      return {id:'curated-'+day+'-'+slot.id,date:day,layerIds:[layer.id],
        title:slot.title,brief:slot.brief,cta:layer.cta,
        audience:effective.layers[layer.id].audience,priority:20,composite:false,
        sections:[slot.title],status:'suggestion',curated:true,
        requestedFormat:slot.format,requestedTime:slot.time};
    })}:combine(candidates,bounds.max);
    const {posts:chosen,omitted}=result;
    dayCards.push({date:day,holiday:inHoliday(day),nswHoliday:inNSWHoliday(day),nswWesternOnly:inNSWWesternExtension(day),
      publicHoliday:bounds.publicHoliday,publicHolidayName:bounds.publicHolidayName,
      partialPublicHoliday:bounds.partialPublicHoliday,longWeekend:bounds.longWeekend,
      postingCategory:bounds.category,minimum:bounds.min,maximum:bounds.max,
      eventAnchors:anchorsByDay.get(day)||[],
      manualPlan:manual,signature:manual?(dayPlan.signature||null):null,omitted,count:chosen.length});
    posts.push(...chosen);
  }
  const composites=posts.filter(p=>p.composite);
  const videoIds=new Set();
  // Monthly ratios are independent. Composites take precedence, then evenly-seeded candidates.
  for(const month of [...new Set(posts.map(p=>p.date.slice(0,7)))]){
    const current=posts.filter(p=>p.date.startsWith(month)&&!p.curated);
    const groups=new Map();
    for(const post of current){
      const effective=settingsForDate(settings,post.date);
      if(!groups.has(effective))groups.set(effective,[]);
      groups.get(effective).push(post);
    }
    for(const [effective,group] of groups){
      const count=Math.round(group.length*effective.videoShare/100);
      const composite=group.filter(p=>p.composite),other=group.filter(p=>!p.composite)
        .sort((a,b)=>numberHash('video-'+a.id)-numberHash('video-'+b.id));
      for(const p of [...composite,...other.slice(0,Math.max(0,count-composite.length))])videoIds.add(p.id);
    }
  }
  for(const p of posts){
    p.format=p.curated?(p.requestedFormat==='video'?'30-second vertical video':p.requestedFormat):
      videoIds.has(p.id)?'30-second vertical video':['image','carousel','link'][numberHash('format-'+p.id)%3];
    p.aspectRatio=p.format.startsWith('30-second')?'9:16':p.format==='link'?'1.91:1':'4:5';
    p.size=p.format.startsWith('30-second')?'1080×1920':p.format==='link'?'1200×630':'1080×1350';
    p.durationSeconds=p.format.startsWith('30-second')?30:null;
    const anchor=settingsForDate(settings,p.date).postingTime||'auto';
    const index=posts.filter(other=>other.date===p.date).indexOf(p);
    const timing=suggestedTimeOfDay(p.date,index,dayPostingBounds(p.date,settingsForDate(settings,p.date).limits),p,anchor);
    p.suggestedTime=p.curated?p.requestedTime:timing.time;
    p.timeOfDaySignal={window:timing.window||'user-selected',reason:timing.reason,timeZone:'Australia/Brisbane'};
    p.creativeVariants=creativeVariantsFor(p,settingsForDate(settings,p.date).delivery);
    p.destinations=[...new Set(p.creativeVariants.filter(v=>v.distribution==='organic').map(v=>v.platform))];
    // The existing social post editor supports only the four connected club channels.
    // The Noticeboard is a separate, unconnected pilot and is never sent there.
    p.channels=p.destinations.filter(id=>id!=='noticeboard');
    p.storyboard=p.durationSeconds? p.sections.length>1?['0-3s: Hook',...p.sections.map((s,i)=>'Segment '+(i+1)+': '+s),'Final 3s: Club link / call to action']:['0-3s: Hook','3-24s: '+p.sections[0],'24-30s: Call to action']:[];
  }
  return {startMonth,posts,days:dayCards,totals:{posts:posts.length,videos:posts.filter(p=>p.durationSeconds).length,combined:composites.length,omitted:dayCards.reduce((n,d)=>n+d.omitted,0)}};
}

export function creativeVariantsFor(post,delivery={}){
  const video=isVideo(post);
  const organic=delivery.organic||['facebook','instagram','youtube','tiktok','noticeboard'];
  const paid=delivery.paid||[];
  const paidPlanning=Boolean(delivery.paidPlanning);
  return CREATIVE_PRESETS.filter(p=>{
    const selected=p.distribution==='organic'?organic.includes(p.platform):paidPlanning&&paid.includes(p.platform);
    const suitable=p.kind==='poster'||p.kind==='both'||(video?p.kind==='video':p.kind==='image');
    return selected&&suitable;
  }).map(p=>{
    const asset=p.kind==='poster'?'Still-image adaptation':p.kind==='image'?'Image / carousel':video?'Video':'Image';
    const fileFormats=p.kind==='both'&&!video?['JPG','PNG']:p.fileFormats;
    const safeZone=p.safeZone&&Number.isFinite(p.safeZone.top)?{
      topPercent:Math.round(p.safeZone.top*100),bottomPercent:Math.round(p.safeZone.bottom*100),
      sidePercent:Math.round(p.safeZone.sides*100),
      topPixels:Math.ceil(p.height*p.safeZone.top),bottomPixels:Math.ceil(p.height*p.safeZone.bottom),
      sidePixels:Math.ceil(p.width*p.safeZone.sides),label:p.safeZone.label
    }:{label:p.safeZone.label};
    const thumb=MASTER_ASSET_PRESETS.find(t=>t.id===p.thumbnailPreset);
    return {
      id:p.id,platform:p.platform,placement:p.placement,distribution:p.distribution,
      width:p.width,height:p.height,ratio:p.ratio,size:p.width+' × '+p.height,
      asset,provisional:Boolean(p.provisional),note:p.note,
      specVersion:CREATIVE_SPEC_VERSION.id,reviewedOn:p.reviewOn,sourceUrl:placementSources[p.sourceKey],
      fileFormats,maximumDurationSeconds:p.durationMaxSeconds??null,
      recommendedDurationSeconds:p.recommendedDurationSeconds??(video?30:null),
      maxFileMB:p.maxFileMB??null,carousel:p.carousel||null,safeZone,
      thumbnail:thumb?{label:thumb.label,width:thumb.width,height:thumb.height,ratio:thumb.ratio}:null,
      checklist:video?['Master footage','Platform-specific edit','Captions/subtitles','Sound/music rights','Safe zone and CTA preview','Thumbnail if supported','Final approval']:
        ['Original artwork','Platform-specific crop','Legible text and alt text','Image rights','CTA and link check','Final approval'],
      approval:p.distribution==='paid'?'Requires explicit ad budget, targeting and launch approval':'Editorial approval before posting',
      status:p.distribution==='paid'?'Unapproved paid creative':'Organic creative suggestion'
    };
  });
}

export const QLD_REDLAND_PUBLIC_HOLIDAYS=Object.freeze(Object.fromEntries(entries));
const publicHoliday=new Map(entries);
const oneDay=86400000;
const asDate=day=>Date.parse(day+'T00:00:00Z');
const formatDate=ms=>new Date(ms).toISOString().slice(0,10);
const weekday=day=>new Date(asDate(day)).getUTCDay();
const nonworkingDay=day=>Boolean(publicHoliday.get(day))||[0,6].includes(weekday(day));
export function calendarDaySignals(day){
  const start=asDate(day),dow=weekday(day);
  const name=publicHoliday.get(day)||'';
  let lower=start,upper=start;
  for(let n=0;n<6&&nonworkingDay(formatDate(lower-oneDay));n++)lower-=oneDay;
  for(let n=0;n<6&&nonworkingDay(formatDate(upper+oneDay));n++)upper+=oneDay;
  const days=(upper-lower)/oneDay+1;
  const longWeekend=nonworkingDay(day)&&days>=3&&
    Array.from({length:days},(_,i)=>weekday(formatDate(lower+i*oneDay))).some(w=>w===0||w===6);
  return {
    publicHoliday:Boolean(name),publicHolidayName:name,longWeekend,
    partialPublicHoliday:day.endsWith('-12-24')?'Christmas Eve (from 6 pm)':'',
    redlandShowHoliday:name.includes('City of Redland'),
    weekday:dow
  };
}
